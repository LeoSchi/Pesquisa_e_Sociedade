# Bem-vindo a Curitiba

Guia para estrangeiros que chegam a Curitiba: informações sobre a cidade, pontos turísticos, documentação, emprego e saúde, em português, inglês, espanhol e francês.

## Funcionalidades

- Site em 4 idiomas (PT, EN, ES, FR) com troca instantânea
- Modo claro e escuro, com a escolha salva no navegador
- Aba Documentação com passo a passo, custo e prazo, glossário e checklist com progresso
- Impressão da lista de documentos e geração de PDF
- Telefones de emergência clicáveis e link de mapa em cada ponto turístico
- Assistente de perguntas e respostas (chat)
- Acessibilidade: link "Pular para o conteúdo" e navegação por teclado

## Estrutura

```
index.html   página base e carregamento dos scripts
style.css    estilos e temas claro/escuro
app.js       interface (React) e lógica
dados.js     todo o conteúdo e as traduções
```

## Tecnologias

HTML, CSS, JavaScript, React 18 (via CDN) e jsPDF.

## Aviso

As informações são orientativas. Regras, prazos, horários e valores podem mudar. Confirme sempre nos sites oficiais.
